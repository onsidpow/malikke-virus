# 말리끄 바이러스

다비 고등학교 구조 캠페인 FPS. 모바일 터치 및 키보드·마우스 조작을 지원합니다.

## 임무

1. 좀비를 모두 처치하라
2. 지하실 전원 스위치를 올려라
3. 체육관으로 들어가라

## 조작

- 터치: 왼쪽 화면 드래그 이동, 오른쪽 화면 드래그 조준, 사격·재장전·상호작용 버튼
- 키보드: WASD 이동, Shift 달리기, R 재장전, E 상호작용, M 안내도, Esc 일시정지
- 마우스: 조준 및 클릭 사격

## 운영

GitHub Pages에서 main 브랜치의 루트 폴더를 배포합니다. index.html, style.css, game.js를 수정한 후 main에 커밋하면 자동으로 갱신됩니다. 별도 빌드나 외부 라이브러리가 필요하지 않습니다.
